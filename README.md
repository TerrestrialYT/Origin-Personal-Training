# Origin Personal Training | Premium Web Presence

A bespoke, highly optimized, single-page website built for **Origin Personal Training**, an exclusive, high-end fitness brand operating out of premium locations in Singapore (Tanglin Mall and Raffles Place). 

Designed with a sleek, monochromatic aesthetic, this project focuses on luxury branding and a streamlined lead-generation funnel to drive high-ticket client acquisitions.

**Live Demo:** [View Live Site Here]([https://terrestrialyt.github.io/YOUR-REPO-NAME-HERE](https://terrestrialyt.github.io/Origin-Personal-Training/))

## ✨ Key Features

* **High-Conversion Architecture:** Strategically designed to funnel traffic directly into the client's consultation booking pipeline (Google Forms) and direct communication channels (WhatsApp).
* **Luxury Monochromatic Aesthetic:** A striking, minimalist UI utilizing deep blacks, crisp whites, and sharp typography to reflect the brand's elite positioning.
* **Pure Performance:** Built without heavy frameworks or external image dependencies. All assets are local for lightning-fast load speeds, crucial for premium clientele.
* **Mobile-Optimized UI/UX:** Built with a mobile-first approach using Tailwind CSS, ensuring a flawless browsing experience on all devices.
* **Cinematic Animations:** Integrated AOS (Animate On Scroll) library for a sophisticated, dynamic browsing experience.

## 🛠️ Tech Stack

* **HTML5:** Semantic markup for structure and accessibility.
* **Tailwind CSS:** Utility-first CSS framework (via CDN) for rapid, precise styling.
* **AOS Library:** Scroll animation logic (via CDN).
* **Google Fonts:** 'Montserrat' (Headings) & 'Inter' (Body text).

## 🚀 Deployment (GitHub Pages)

This project is built as a pure, single-file static website (`index.html`) with no build steps or bundlers required, making it incredibly easy to host directly on GitHub Pages.

1. Create a new repository on GitHub and upload your `index.html` file.
2. Ensure all local images (`logo.png`, `hero.jpg`, `trainer.jpg`, `studio.jpg`) are uploaded to the **root** folder, directly next to `index.html`.
3. Go to your repository **Settings**.
4. Navigate to **Pages** in the left sidebar.
5. Under "Build and deployment", set the **Source** to `Deploy from a branch`.
6. Under "Branch", select `main` (or `master`), leave the folder as `/ (root)`, and click **Save**.
7. Wait 1-2 minutes, and your live URL will appear at the top of the Pages settings screen.
